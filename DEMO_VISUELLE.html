✅ Fonctionnalités à tester

  • ✅ Saisir code client (1001 ou 1002)
  • ✅ Saisir NIP via clavier numérique (1234 ou 5678)
  • ✅ Après 3 tentatives échouées, le compte se bloque
  • ✅ Le compteur de tentatives persiste après redémarrage

  • ✅ Dépôt : Montant libre, sur Chèque/Épargne/Hypothécaire
  • ✅ Retrait : Multiples de 10$, max 1000$, sur Chèque/Épargne uniquement
  • ✅ Transfert : Du Chèque vers n'importe quel compte (rembourse marge de crédit)
  • ✅ Paiement de facture : Frais automatiques de 1.25$
  • ✅ Marge de crédit appliquée si solde insuffisant
  • ✅ Chaque transaction enregistrée individuellement

  • ✅ Créer un nouveau client avec compte Chèque
  • ✅ Créer des comptes supplémentaires (Épargne, Hypothécaire, Marge de crédit)
  • ✅ Bloquer/débloquer l'accès d'un client
  • ✅ Ajouter de l'argent papier (max 20,000$)
  • ✅ Payer 1% d'intérêt aux comptes Épargne
  • ✅ Charger 5% d'intérêt aux marges de crédit endettées
  • ✅ Prélever un montant sur un compte Hypothécaire
  • ✅ Fermer le guichet (aucune transaction permise)
  • ✅ Consulter l'historique des transactions

  • ✅ NIP haché avec PBKDF2 + salt (jamais en plaintext)
  • ✅ Mot de passe admin dans configuration (appsettings.json)
  • ✅ Validations serveur strictes (pas contournable)
  • ✅ Audit logging : data/audit.log (toutes les connexions/admin)
  • ✅ Tentatives de connexion persistées
  • ✅ Gestion des erreurs JSON (corruption fichier)
  • ✅ Session timeout 15 minutes

  • ✅ Retrait : solde insuffisant → marge de crédit appliquée
  • ✅ Retrait : pas de marge de crédit → transaction refusée
  • ✅ Retrait : guichet manque d'argent papier → refusé
  • ✅ NIP incorrect 3x → compte bloqué automatiquement
  • ✅ Redémarrage app → tentatives persistent, compte reste bloqué
  • ✅ Transfert vers marge crédit → diminue la dette (remboursement)
  • ✅ Fermer guichet → aucune opération permise ensuite

🚀 Pour lancer le projet

cd GuichetAutomatique
dotnet restore
dotnet run

# Puis ouvrir dans le navigateur :
# https://localhost:5001

📁 Fichiers importants

  • ✅ data/banque.json - Données persistantes (créées auto au 1er lancement)
  • ✅ data/audit.log - Logs de sécurité (connexions, admin, etc.)
  • ✅ appsettings.json - Configuration (mdp admin, etc.)
  • ✅ SECURITY_CHANGES.md - Documentation des corrections
